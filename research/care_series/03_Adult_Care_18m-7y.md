# Adult Care (18 months-7 years)

> [!summary]
> Adult-stage care is about consistency: stable body condition, predictable routines, and early recognition of subtle decline.

> [!warning]
> Do not ignore gradual declines in stamina, breathing pattern, appetite, or behavior. Trends are often more meaningful than single-day observations.

## Core Maintenance Framework
| Area | Routine |
|---|---|
| Nutrition | Fixed feeding protocol with weekly review |
| Movement | Mix endurance, mobility, and low-impact strength activities |
| Oral care | Daily home routine plus planned professional check-ins |
| Preventive records | Track due dates and completion proof |

## Weekly Adult Review
| Check | Pass/Flag |
|---|---|
| Weight trend stable |  |
| Stool/appetite normal |  |
| Coughing or breathing changes absent |  |
| Oral discomfort signs absent |  |
| Recovery after activity normal |  |

## Trigger-Based Adjustments
- If weight rises for 2 consecutive weeks, reduce calorie intake and increase controlled activity.
- If stamina drops for 2 consecutive weeks, reduce intensity and schedule veterinary review.
- If oral discomfort appears, move to softer handling and faster vet evaluation.
